## 3. 信息流（mermaid）

```mermaid
flowchart TB
  subgraph site [官网单页]
    H[顶栏 品牌/锚点/语言]
    Hero[首屏 标语+说明+安装+实测一行]
    How[怎么用 4 步]
    Page[决策页说明+截图]
    Demo[演示 可选]
    Drift[范围偏离+已知局限]
    Meas[实测摘要表]
    Foot[页脚]
    H --> Hero --> How --> Page --> Demo --> Drift --> Meas --> Foot
  end

  subgraph readme [README]
    L[语言链接]
    T[标题+标语+安装]
    S[状态引用块]
    Img[至多两张真实资产图]
    Body[组件/流程/安装/用法/格式/检查/实测/状态]
    L --> T --> S --> Img --> Body
  end
```

```mermaid
flowchart LR
  A["Codex /plan"] --> B["Stop hook"]

  B --> D["plan.html"]
  D -->|"回传 JSON"| E["下一条用户消息"]
  E --> F["实现"]

```
